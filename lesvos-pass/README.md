# Lesvos Pass — ιστοσελίδα (έκδοση 1: αρχική σελίδα)

## Αρχεία
- `index.html` — η δομή της σελίδας
- `css/styles.css` — χρώματα, γραμματοσειρές, διάταξη (και για κινητό)
- `js/i18n.js` — ΟΛΑ τα κείμενα σε αγγλικά, τουρκικά, ελληνικά
- `js/main.js` — λειτουργίες: αλλαγή γλώσσας, χάρτης, προσφορές, μενού κινητού

## Τι αλλάζεις συνήθως
- **Κείμενα:** στο `js/i18n.js`, πάντα και στις τρεις γλώσσες.
- **WhatsApp και email:** στην αρχή του `js/main.js`, στο `CONFIG`.
- **Συνεργαζόμενα μαγαζιά:** ΟΛΑ βρίσκονται στο `js/partners.js`. Για νέο μαγαζί αντιγράφεις
  ένα μπλοκ, αλλάζεις όνομα, κατηγορία, περιοχή, προσφορά (3 γλώσσες) και αναζήτηση Google Maps.
  Όταν η προσφορά είναι πραγματική, βάλε `example: false`. Νέες περιοχές/κατηγορίες μπαίνουν στο ίδιο αρχείο.
  Προαιρετικά: `address` (π.χ. "Άγρα, 811 05 Λέσβος") και `phone` (π.χ. "+30 2253 012345"). Φαίνονται και χωρίς ίντερνετ.
- **Μετά από κάθε αλλαγή** ανέβασε την έκδοση στο `sw.js` (v2 → v3 ...), για να πάρουν όλοι τη νέα έκδοση.

## Ανέβασμα στο GitHub Pages
Ανέβασε ολόκληρο τον φάκελο (index.html, css/, js/) στο repository, όπως με τα demo sites.

## Νομικές σελίδες
- `terms.html` (Όροι χρήσης), `sale.html` (Όροι πώλησης), `privacy.html` (Απόρρητο και cookies)
- Τα κείμενα και στις 3 γλώσσες είναι στο `js/legal-content.js`.
- Στην αρχή του ίδιου αρχείου, στο `COMPANY`, συμπληρώνεις μία φορά επωνυμία, διεύθυνση, ΑΦΜ, ΓΕΜΗ,
  email, τηλέφωνο και ημερομηνία ενημέρωσης. Μπαίνουν αυτόματα σε όλα τα κείμενα.
- ΠΡΟΣΧΕΔΙΟ: να ελεγχθούν από δικηγόρο πριν τη δημοσίευση.

## Κανόνες ώστε η σελίδα να μένει επαγγελματική (και στο κινητό)
1. **Πρώτα κινητό.** Κάθε αλλαγή τη δοκιμάζεις στον Chrome με F12 → Ctrl+Shift+M σε 360, 390 και 430 πλάτος.
   Τίποτα δεν πρέπει να «βγαίνει» δεξιά από την οθόνη.
2. **Κουμπιά και σύνδεσμοι** τουλάχιστον 40–44 pixel ύψος, για να πατιούνται άνετα με το δάχτυλο.
3. **Κείμενα προσφορών σύντομα:** όνομα έως ~30 χαρακτήρες, προσφορά έως ~45. Ίδιο ύφος σε όλα
   (π.χ. «10% έκπτωση σε…», «Κέρασμα … με …»).
4. **Μόνο τα χρώματα και οι γραμματοσειρές της σελίδας** (βρίσκονται στην αρχή του css/styles.css, στο :root).
5. **Φωτογραφίες (αν μπουν στο μέλλον):** μορφή WebP, πλάτος έως 1600px, μέγεθος κάτω από 200KB η καθεμία.
6. **Κάθε κείμενο και στις 3 γλώσσες.** Αν λείπει μετάφραση, η σελίδα δείχνει τα αγγλικά.
7. **Έλεγχος πριν ανεβάσεις:** άνοιξε F12 → Console. Δεν πρέπει να υπάρχουν κόκκινα σφάλματα.
